# Referencias APA — Node.js y Express (tesis)

Para **Definiciones conceptuales** (Cap. II) y **Referencias bibliográficas**.

---

## Node.js

**Referencia (APA 7):**

Mammino, M., & Luciano, S. (2020). *Node.js design patterns: Design and implement production-grade Node.js applications using proven patterns and techniques* (2ª ed.). Packt Publishing.

**Cita en el texto:** (Mammino & Luciano, 2020)

**Definición sugerida:**

Node.js: Entorno de ejecución de JavaScript del lado del servidor que permite construir aplicaciones de red escalables mediante entrada/salida asíncrona y el ecosistema npm. En el prototipo IECA sustenta la API REST del backend, donde se procesan autenticación, validación de datos, reglas de negocio, alertas por correo y acceso a Firestore (Mammino & Luciano, 2020).

---

## Express

**Referencia (APA 7):**

Brown, E. (2019). *Web development with Node and Express: Leveraging the JavaScript stack for web application development* (2ª ed.). O'Reilly Media.

**Cita en el texto:** (Brown, 2019)

**Definición sugerida:**

Express: Framework web para Node.js orientado a la creación de APIs y servicios HTTP, que facilita definir rutas, middleware y endpoints REST de forma modular. En este proyecto organiza los módulos de la API (`/api`), incluyendo seguridad, validación con Zod y comunicación con Firestore (Brown, 2019).
